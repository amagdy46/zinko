# Handoff: Zinko M1, capture with Scrapling

## Goal and limits

Deliver milestone M1 from `docs/roadmap.md`: capture a page under 3 consent scenarios and get decoded hits. M1 is built in these places:
- `packages/capture`: network requests, the `dataLayer` shim, cookies, CMP state and screenshots.
- The autoconsent scenarios: none, accept and reject.
- Two new decoders, for Google Ads and TikTok.
- `packages/fixtures`: static sites, each with one known tracking bug.
- The Scrapling capture engine, in the `apps/browser` container.

Product and architecture are in `docs/product.md` and `docs/architecture.md`, and the reasoning is in `RESEARCH.md`.

Ask the user before you:
- push to `main` (see Blockers);
- publish to npm (on hold);
- deploy anything;
- add Cloudflare secrets;
- use stealth browsing on sites the user has no permission to audit.

The 5 public bot-protected sites in the spike are only loaded, the way a visitor's browser would load them.

## Decisions

- **Scrapling is the capture engine.** The user decided this. It runs in Python inside the `apps/browser` container, behind the generated `Browser` service, so everything else stays TypeScript.
- **Plain Playwright stays in the same container** as the baseline and as the fallback for any capability Scrapling lacks.
- **Findings are deterministic rules.** The LLM only explains them, and every finding cites its evidence.
- **The GA4 `gcs` value is "G1" plus the ad_storage and analytics_storage digits.** How `gcd` is decoded is unverified.
- **Licenses:** Zinko is AGPL-3.0, and efforge is MIT.
- **Tooling:** Vite+ (oxlint and oxfmt) for lint and format. `AGENTS.md` holds the rules for agents working in the repo.

## Blockers and risks

- **Deploy runs on every push.** Every push or PR to `main` starts `.github/workflows/deploy.yml`, which fails without the Cloudflare secrets. So far each run has been cancelled by hand. Options:
  - make it manual-only, with `workflow_dispatch`, until the secrets exist;
  - add the secrets.

  Ask the user which.
- **Python joins a TypeScript repo.** The Scrapling container adds Python, so keep it isolated in `apps/browser` with its own lockfile (`uv` or pip-tools), and keep its HTTP contract typed on the TypeScript side with Effect Schema.
- **`/tmp` is a 4 GB tmpfs.** Use `TMPDIR=$HOME/.cache/tmp`.
- **The formatter needs a git repo.** `~/.gitignore` contains `*`, so a project outside a git repo looks empty to it.

## Resume point

Run the **M1 spike** as a throwaway script under `spikes/m1-capture/`. It isn't committed until its results are written up.

The spike drives Scrapling `StealthySession` against `packages/fixtures`-style test pages. Start with one local static page that pushes to `dataLayer`, loads gtag in GA4 and sends a POST batch. It must show that:
1. An init script runs before page scripts, by capturing the first `dataLayer.push`.
2. Request URLs **and POST bodies** are captured for `/g/collect`.
3. Cookies can be read.
4. A screenshot can be taken.

**Done when** `spikes/m1-capture/RESULTS.md` has a table with yes, no or workaround for each capability, comparing Scrapling with plain Playwright (and patchright if time allows). Then decide the engine contract and record it as `docs/decisions/0002-capture-engine.md`.
