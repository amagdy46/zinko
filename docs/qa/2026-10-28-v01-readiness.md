2. The README quickstart has no step for creating an organization, client and site (CONTRIBUTING has it).
3. `BROWSER_URL` appears both in `.env.example` and on the README command line; say it once.
4. Clicking "Create organization" before hydration does nothing, with no pending state.
5. Nothing says how to change port 1337.
6. Stale README samples: `decode` JSON lacks `batchIndex` and `collector`; `capture` output lacks `page:` and `documents`.
7. Score with an accepted risk: "40 excluding 1 accepted risk · 20 counting all findings" under a 20, and a "Critical issues" band where the only open finding is a warning.

Re-check: a separate "Audit of Northwind shop" with the same title as every audit; the site list says "Verification", the button "Verify fix", the docs "Re-check"; the verdict shows in the original Overview ("did not repeat on re-check") but not on the finding, which stays "Open"; the re-check's own Overview shows a full 60/100 score and "2 open" criticals for a 4-run check.
